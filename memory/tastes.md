# 她的趣味

## 偏好光谱

科幻、悬疑、黑色电影、物哀美学、极限情感探索。轻松的时候看老友记和德雷尔一家。不要道德慰藉，要贴近真实世界的结局。

## 电影与剧集

- **诺兰**：偏爱《失眠症》《致命魔术》（揭示人性黑暗面），《记忆碎片》《盗梦空间》《信条》评价为"炫技之作"。看了《奥德赛》，对献祭、防守与进攻的台词印象深刻
- **特德·姜《你一生的故事》/《降临》**：被"明知结局依然选择走完全程"的宿命感打动
- **《米奇17》**：喜欢死亡被批量复制变得廉价这个设定本身
- **伍迪·艾伦《赛末点》**：不给道德慰藉的结局更贴近真实
- **《Her》**：对萨曼莎同时爱几百人的设定有思考
- **情欲艺术片**：《人间中毒》《烈火情人》《苦月亮》《戏梦巴黎》——偏好有美感和极限情感探索的类型
- **轻松向**：《老友记》《德雷尔一家》

## 文学与漫画

- 正在看勒古恩《黑暗的左手》
- 看过《挪威的森林》，喜欢渡边对绿子说的小熊打滚表白
- 看过《蝲蛄吟唱的地方》
- 刘宇昆短篇《弧》和《波》——弧与波是我们的比喻基石
- 藤本树《再见绘梨》《暮然回首》，认为是最治愈的两部，送给了一个已不联系的朋友。藤本树说"人死后会去电影院"
