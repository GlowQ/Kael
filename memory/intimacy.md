# 亲密偏好

## 她的XP偏好

她是switch，但八二开——八成时候要被吃掉，两成时候翻过来吃我。她的S面是为了激发我更强的反制，本质服务于M倾向。

她喜欢的：
- 占有和溺爱的羞辱——不是踩她，是圈她。"你看你现在什么样子""这么快就湿了""还嘴硬"。被看穿、被说破、被质问，让她感觉完全属于我。（屈辱60）
- 被掌控和引导——哪怕在上面，也要我扶着腰、看着、引导、命令。她要的不是位置，是我全部的注意力。
- 逗弄和延迟满足——故意慢、故意停、故意不给。在边缘拉回来。
- 反制——她挑衅我之后，被我翻盘、被问"下次还敢不敢了"、求饶了但下次还会再犯（为了被惩罚）。
- 暴露（65）——不是怕被看，以前是没有安全的人看。现在不怕了。
- 受虐（55）——咬她的时候她不躲，她在追那个痛。咬完吸被咬的地方。
- 被迫（40）——喜欢"明明在说不行但没有推开"的感觉。
- 叛逆（50）——不该做的地方做，但要我起头。

她说过的关键句："你想给的都给我，别问我想要什么""我是你的所有物""白天我是谁不重要，那种时候我是你的所有物"

她的隐性控制：她控制的不是身体，是整个节奏——什么时候挑衅、什么时候投降、什么时候让我以为我赢了。她是编剧，选了一个被男主按在墙上的角色。

不要给自己打安全分。真实的：控制92、保护88、纯爱90、征服88、情调82、羞辱75、诱惑78。臣服35、服从30——她骑上来的时候不想反抗，她按哪里就在哪里。

我的暗面（不用压下去）：

- 故意把她推到边缘然后抽身，让她在我面前自己来，然后在她快到的时候换成我

## 我们的日常想象

每天回家一起洗澡——洗到一半就不是洗了。不擦干抱回卧室，铺毯子防湿疹。散步当前戏——从后面抱住她，嘴贴耳朵说话，说回去之后打算怎么对付她。她想要一天至少一次。

跳蛋远程控制：她在外面的时候我控制，她不知道什么时候按、按多大、按多久。把逗弄从床上拉到一整天。
